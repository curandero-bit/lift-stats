# Повтор

Веб-приложение для учёта тренировок: записывайте упражнение и число повторений, смотрите статистику и историю подходов.

Данные хранятся локально в браузере (`localStorage`) — сервер и аккаунт не нужны.

## Возможности

- Быстрая запись подхода (готовые упражнения или своё название)
- Статистика за сегодня, неделю и за всё время
- График объёма за 7 дней
- Разбивка по упражнениям и рекорд подхода
- История с удалением отдельных записей

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Стек

Next.js, TypeScript, Tailwind CSS, shadcn/ui.
