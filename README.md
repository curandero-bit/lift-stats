# Повтор

Веб-приложение для учёта тренировок: записывайте упражнение, повторения и вес, смотрите статистику и историю подходов.

Данные хранятся локально в браузере (`localStorage`) — сервер и аккаунт не нужны.

## Возможности

- Быстрая запись подхода (упражнение, повторения, вес в кг — необязательно)
- Статистика за сегодня, неделю и за всё время, тоннаж (вес × повторы)
- График объёма за 7 дней
- Разбивка по упражнениям, рекорд подхода и максимальный вес
- История с удалением отдельных записей

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Стек

Next.js, TypeScript, Tailwind CSS, shadcn/ui.
